# Claude Code 명령어 치트시트

## 설치 & 인증
| 명령어 | 설명 |
| --- | --- |
| `npm install -g @anthropic-ai/claude-code` | CLI 전역 설치 |
| `claude --version` | 설치 버전 확인 |
| `claude` | 현재 폴더에서 세션 시작 (최초 실행 시 인증) |
| `claude /logout` | 로그아웃 |

## 세션 제어 슬래시 명령어
| 명령어 | 설명 |
| --- | --- |
| `/help` | 사용 가능한 명령어 목록 표시 |
| `/clear` | 대화 컨텍스트 완전 초기화 |
| `/compact` | 지금까지의 대화를 요약해 컨텍스트 절약 |
| `/status` | 현재 모델, 권한 모드, 컨텍스트 사용량 확인 |

## Git 연동
| 요청 예시 | 용도 |
| --- | --- |
| "스테이징된 변경 사항으로 커밋 메시지 작성해줘" | 커밋 메시지 자동 작성 |
| "main 대비 현재 브랜치 PR 설명 작성해줘" | PR 설명 자동 작성 |
| "현재 diff를 보안/성능 관점에서 리뷰해줘" | AI 코드 리뷰 |

## 디버깅 & 리팩토링
| 요청 예시 | 용도 |
| --- | --- |
| "이 에러 로그의 원인을 분석하고 고쳐줘" | 스택 트레이스 기반 디버깅 |
| "이 함수의 시그니처를 바꾸고 호출부도 함께 수정해줘" | 멀티 파일 리팩토링 |
| "이 클래스에 대한 단위 테스트를 작성하고 실행해줘" | 테스트 작성 및 검증 |

## 플러그인 & MCP
| 명령어 | 설명 |
| --- | --- |
| `claude plugins list` | 설치 가능한 플러그인 목록 |
| `claude plugins install <name>` | 플러그인 설치 |
| `claude plugins update <name>` | 플러그인 업데이트 |

## 안전 수칙
- 파일 삭제, 강제 푸시, DB 마이그레이션 등 되돌리기 어려운 작업은 항상 사람이 직접 승인합니다.
- 커밋 전 `git status`로 민감 정보 포함 여부를 다시 확인합니다.
- 처음 다루는 저장소에서는 기본(수동 승인) 권한 모드로 시작합니다.

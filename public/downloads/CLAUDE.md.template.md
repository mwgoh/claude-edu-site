# 프로젝트 개요
이 저장소는 ○○ 서비스의 (백엔드 API / 프론트엔드 앱 / CLI 도구)입니다.
주요 스택: (예: Node.js + Express + PostgreSQL)

# 개발 명령어
- 개발 서버 실행: npm run dev
- 테스트 실행: npm test
- 린트 검사: npm run lint
- 빌드: npm run build

# 아키텍처 요약
- src/ : 애플리케이션 소스 코드
- src/api/ : REST API 라우트
- src/services/ : 비즈니스 로직
- tests/ : 단위 및 통합 테스트

# 코딩 규칙
- 함수형 컴포넌트만 사용하고 클래스형 컴포넌트는 작성하지 않습니다.
- 커밋 메시지는 Conventional Commits 형식을 따릅니다 (feat:, fix:, refactor: 등).
- 새 API 엔드포인트를 추가할 때는 반드시 통합 테스트를 함께 작성합니다.
- 외부 패키지를 새로 추가하기 전에 팀 리뷰를 거칩니다.

# 주의 사항
- /legacy 디렉터리는 종료 예정 코드이므로 새 기능을 추가하지 않습니다.
- 데이터베이스 마이그레이션은 반드시 리뷰 후 병합합니다.
- .env, 자격 증명 파일은 절대 커밋하지 않습니다.

# 리뷰 시 확인할 것
- 보안: SQL 인젝션, XSS, 하드코딩된 자격 증명 여부
- 성능: 불필요한 반복 쿼리(N+1), 캐싱 누락 여부
- 테스트: 신규/변경 로직에 대한 테스트 커버리지
